# preview-base.html 生成步骤

> 在本地生成带设计锚点的 `preview-base.html`，供设计智能体注入 CSS 后本地预览。
> 目标：得到一个在 `file://` 协议下可离线查看的完整页面。

## 前置条件

- Quartz 项目已初始化（`npx quartz create`）
- `quartz.config.ts` 已按用户选择配置
- 笔记内容已放入 `content/` 目录

---

### 步骤 1：确认 quartz.config.ts 已按用户选择配置

**状态：⚠️ 需手动**

检查 `quartz.config.ts` 中的 `layout` 数组，确保所需组件已启用且顺序正确。

```powershell
# 查看当前配置
Get-Content .\quartz.config.ts | Select-String 'layout'
```

---

### 步骤 2：运行 Quartz 构建

**状态：✅ 直接可用**

```powershell
npx quartz build
```

构建产物在 `public/` 目录下。主页面为 `public/index.html`。

---

### 步骤 3：复制 public/index.html → preview-base.html

**状态：✅ 直接可用**

```powershell
Copy-Item .\public\index.html .\preview-base.html
```

---

### 步骤 4：注入 `<style id="design-css"></style>` 到 `</head>` 前

**状态：⚠️ 需手动**

在 `preview-base.html` 的 `</head>` 前插入样式占位标签。设计智能体将向此标签写入 CSS。

```powershell
# PowerShell 一行注入
$html = Get-Content .\preview-base.html -Raw -Encoding UTF8
$html = $html -replace '</head>', "`n  <style id=`"design-css`"></style>`n</head>"
$html | Out-File .\preview-base.html -Encoding UTF8 -NoNewline
```

---

### 步骤 5：内联外部 CSS/JS（file:// 协议兼容）

**状态：⚠️ 需手动**

`file://` 协议下浏览器不允许加载外部 CSS/JS。需将 `<link>` 和 `<script src="...">` 替换为内联版本。

```powershell
# 将所有外部 CSS 转为内联 <style>
# 将所有外部 JS 转为内联 <script>
# 具体方法取决于外部资源的路径结构，通常需要手工操作
Write-Host '建议：在浏览器中打开 http://localhost:8080 调试后，再手动内联关键样式/脚本到 preview-base.html'
```

> 这一步也可以通过 `npx quartz build --serve` 先在本地 `http://localhost:8080` 确认效果，再手动将关键样式复制到 `<style id="design-css">` 中。

---

### 步骤 6：注入版本注释

**状态：✅ 直接可用**

在 `preview-base.html` 顶部注入版本信息注释，便于追踪。

```powershell
$versionComment = "<!-- preview-base generated by quartz-publisher v0.5 | $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') -->`n"
$html = Get-Content .\preview-base.html -Raw -Encoding UTF8
$html = $versionComment + $html
$html | Out-File .\preview-base.html -Encoding UTF8 -NoNewline
```

---

### 步骤 7：清理 public/ + .quartz-cache/

**状态：✅ 直接可用**

保留 `preview-base.html`，清理构建中间产物（可选，建议在最终部署前执行）。

```powershell
Remove-Item -Recurse -Force .\public, .\.quartz-cache -ErrorAction SilentlyContinue
```

---

## 完整脚本（一键执行）

```powershell
# 完整流程：从构建到生成 preview-base.html
npx quartz build
Copy-Item .\public\index.html .\preview-base.html

$html = Get-Content .\preview-base.html -Raw -Encoding UTF8
$version = "<!-- preview-base generated by quartz-publisher v0.5 | $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') -->`n"
$html = $html -replace '</head>', "`n  <style id=`"design-css`"></style>`n</head>"
$html = $version + $html
$html | Out-File .\preview-base.html -Encoding UTF8 -NoNewline

Write-Host 'preview-base.html 已生成。请在 file:// 下打开验证。'
```

*步骤 5（内联外部资源）需根据具体项目结构手工处理，未包含在自动脚本中。*
