# 智慧树 · 首页功能规划 — 模块菜单版

> 文姬出品 · 2026-06-04 · 给伯喈落地用
> 每个模块可独立勾选，用户按需组合

---

## 使用说明

各模块均可单独勾选。勾选后的 CSS 由伯喈从文姬交付的 8 zone patch 中提取对应 zone 写入 `custom.scss`。

| 站点类型 | 推荐模块组合 |
|----------|-------------|
| **两口问茶（极简测试）** | A + E + F + G |
| **智慧树（学术知识库）** | A + B + C + D + E + F + G + H |
| **个人博客** | A + C + E + F + G |
| **项目文档** | A + B + E + F + G |

---

## 模块菜单

### 模块 A · Hero 区

> 首页顶部核心区域：站标题 + 副标题 + 一句话价值主张

| 属性 | 值 |
|------|-----|
| **适用站点** | 所有类型 |
| **前置条件** | `content/index.md` 存在 |
| **独立勾选** | ✓ 可单独勾选 |
| **zone 位置** | `@zone:center` |

**元素规格：**

| 元素 | 选择器 | 字号 | 字色 | 间距 |
|------|--------|------|------|------|
| 主标题 | `.hero-title` | 36px | `#1c1814` | `margin-bottom: 12px` |
| 副标题 | `.hero-subtitle` | 18px | `#6b5f52` | `margin-bottom: 32px` |
| 统计条 | `.home-stats` | 14px | `#6b5f52` | `padding: 16px 0; border-top: 1px solid #d4c9b0` |
| 统计数字 | `.home-stats strong` | 24px | `#1c1814` | — |

CSS 骨架：
```css
.hero-title { font-size: 36px; font-weight: 600; color: #1c1814; margin-bottom: 12px; }
.hero-subtitle { font-size: 18px; color: #6b5f52; margin-bottom: 32px; line-height: 1.6; }
.home-stats { padding: 16px 0; border-top: 1px solid #d4c9b0; display: flex; gap: 36px; }
.home-stats strong { font-size: 24px; color: #1c1814; }
```

完整 CSS 见 8 zone patch 文档 `@zone:center` 区块。

| 属性 | 值 |

**浅色 → 暗色对照表：**

| `--surface` | `#f4efe2` | `#252320` |
| `--fg` | `#1c1814` | `#e8e3d8` |

### 模块 G · 响应式适配

> 为模块 A~D 提供断点式响应式降级

| 属性 | 值 |
|------|-----|
| **适用站点** | 所有站点 |
| **前置条件** | 已勾选的模块是多少，响应式覆盖多少 |
| **独立勾选** | ✓ 可单独勾选 |
| **zone 位置** | `@zone:layout` + 各模块自身 |

**5 断点计划：**

| 断点 | 宽度 | 模块 B（卡片列数） | 模块 C（更新行数） | 三栏布局 |
|------|------|:--:|:--:|------|
| 手机 | 360px | 1 列 | 3 条 | 单栏（隐左/右） |
| 小平板 | 768px | 2 列 | 5 条 | 隐右栏 |
| 平板 | 1024px | 2 列 | 5 条 | 缩右栏 220px |
| 小桌面 | 1440px | 2 列 | 5 条 | 全三栏 |
| 桌面 | 1920px | 2 列 | 5 条 | 全三栏 |

### 模块 H · 性能与无障碍

> 资源加载优先级 + ARIA + 键盘导航

| 属性 | 值 |
|------|-----|
| **适用站点** | 所有站点 |
| **前置条件** | 无 |
| **独立勾选** | ✓ 可单独勾选 |
| **zone 位置** | 全 zone |

**fetchpriority 分级：**

| 资源 | 优先级 | 策略 |
|------|:--:|------|
| 字体 CSS | high | 首屏阻塞 |
| Hero 区图片 | high | 首屏加载 |
| 图谱 JS/Canvas | low | `loading="lazy"` |
| 阅读时间 JS | low | defer |

**ARIA 标注：** 卡片区 `role="navigation" aria-label="项目入口"`，更新区 `role="feed"`，标签云 `role="navigation" aria-label="标签"`

## 伯喈执行清单

1. 确认用户勾选的模块清单
2. 从文姬 8 zone patch 文档中提取对应 zone 的 CSS
3. 替换 `custom.scss` 中对应 `@zone` 锚点
4. `npx quartz build --serve` → `http://localhost:8080` 本地验证
5. 验证通过 → `git push`
6. 文姬验收线上站
