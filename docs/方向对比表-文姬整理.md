## 六方向详细参数

### 1. editorial-monocle 编辑杂志风

```css
:root {
  --bg:      #faf9f6;
  --surface: #ffffff;
  --fg:      #2d2a24;
  --muted:   #6b6358;
  --border:  #e6e3db;
  --accent:  #b85c3a;
  --code-bg: #f4f2ed;
}
```
- 字体：serif display + sans body
- 布局：单栏或双栏，留白奢侈
- 约束：无阴影、无圆角卡片、accent 用最多 2 次

### 2. modern-minimal 现代极简

```css
:root {
  --bg:      #fafbfb;
  --surface: #ffffff;
  --fg:      #1d2125;
  --muted:   #777c82;
  --border:  #e8eaec;
  --accent:  #3b82f6;
  --code-bg: #f4f5f7;
}
```
- 字体：system sans 全站统一
- 布局：content-led，sticky frosted nav
- 约束：hairline 边框、mono numerics、accent + secondary + status 三色系统

### 3. human-approachable 亲和人性化

```css
:root {
  --bg:      #f8f9fa;
  --surface: #ffffff;
  --fg:      #1e293b;
  --muted:   #64748b;
  --border:  #e2e8f0;
  --accent:  #10b981;
  --code-bg: #f1f5f9;
}
```
- 字体：sans display 强字重对比 + system body
- 布局：卡片 grid，舒适间距
- 约束：大圆角 12-18px、微妙阴影仅交互卡片、避免 beige 底色

### 4. tech-utility 技术工具风

```css
:root {
  --bg:      #f8f9fb;
  --surface: #ffffff;
  --fg:      #1e293b;
  --muted:   #64748b;
  --border:  #e2e8f0;
  --accent:  #22c55e;
  --code-bg: #f1f5f9;
}
```
- 字体：sans 全站（一个家族），mono 用于代码/ID
- 布局：密集表格、hairline 边框
- 约束：tabular-nums、状态色 pill、无 hero image

### 5. brutalist-experimental 粗野实验派

```css
:root {
  --bg:      #f8f9fa;
  --surface: #ffffff;
  --fg:      #1a1a1a;
  --muted:   #595959;
  --border:  #1a1a1a;
  --accent:  #e03c28;
  --code-bg: #f0f0f0;
}
```
- 字体：serif display 超大字号 + mono body
- 布局：不对称分栏（如 70%/30%）
- 约束：0-2px 圆角、粗边框 1.5-2px、无阴影无渐变

### 6. 智慧树（文姬自定义）

```css
:root {
  --bg:      #ede3cf;  /* 暖纸底 */
  --surface: #f4efe2;  /* 纸面 */
  --fg:      #1c1814;  /* 墨 */
  --muted:   #6b5f52;  /* 墨淡 */
  --border:  #d4c9b0;  /* 线 */
  --accent:  #b8860b;  /* 琥珀 */
  --code-bg: #f4efe2;
}
```
- 字体：全站宋体（Noto Serif SC / Songti SC / SimSun）
- 布局：Quartz 三栏 grid（240px / 1fr / 280px）
- 特色：SVG 纸纹肌理、暗色 frosted glass 顶栏 72px、4px 纸色滚动条
- 约束：无阴影、单 accent、5px 圆角克制使用
