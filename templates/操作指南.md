## 全局工作流

```
Step 1: 伯喈根据主公选择的布局/功能，生成 preview-base.html（框架已搭好）
        ↓
Step 2: 文姬启动（见下方「文姬操作指南」）
        ↓
Step 3: 文姬询问主公风格偏好 → 主公回答 → 文姬产出 CSS
        ↓
Step 4: 文姬将 CSS 写入 oqc-通信文件.md（按 @zone 分区）
        ↓
Step 5: 伯喈将 CSS 注入 preview-base.html → 主公本地浏览器审核
        ↓
Step 6: 迭代 2-5，直到主公满意
        ↓
Step 7: 伯喈将最终 CSS 转译为 Quartz custom.scss → git push → 线上站
```

## 文姬（设计智能体）操作指南

### 启动流程（初次进入本工作空间）

1. **读取本文件**（操作指南.md）——了解工作流
2. **读取 preview-base.html**——理解页面框架（顶栏/左栏/中栏/页脚的 DOM 结构）
3. **读取 oqc-通信文件.md**——查看伯喈的 Step 1 布局/功能选择记录（zone=layout 区）
4. **在 oqc-通信文件.md 末尾写入确认**：
   ```
   zone=handshake · 已就绪

   已阅读：操作指南 / preview-base / 通信文件。
   确认工作空间为 construction-site/，理解框架结构。
   准备进入风格询问，请主公回应。
   ```

### 视觉装饰流程（必须执行，不可跳过）

**在产出任何 CSS 之前，必须向主公询问以下问题：**

将以下内容写入 `oqc-通信文件.md`：
```
zone=style-inquiry · 等待主公回应

我已理解页面框架。在开始设计之前，请主公告诉我：

① 你希望整体是什么风格？
   例如：温暖纸质 / 极简白 / 暗色学术 / 东方禅意 / 现代杂志 / 其他_____

② 有没有参考网页？
   例如：https://www.bianjing-hours.art/street-intro
   如果有多个，请都给我。

③ 有没有设计"咒语"？（可选）
   例如："像一本泛黄的古书，金色点缀，阅读感舒适"

④ 有没有现成的设计模板/色板？（可选）

请主公逐一回答。
```

**主公回答后**，文姬根据回答产出 CSS，写入通信文件 zone=design。

### 写 CSS 规范

1. **所有 CSS 写入 `oqc-通信文件.md`**（不是直接改 preview-base.html）
2. **按 @zone 分区**：
   ```
   zone=design · 完成

   /* @zone:viewport */
   ...
   /* @zone:topbar */
   ...
   /* @zone:left-sidebar */
   ...
   /* @zone:center */
   ...
   /* @zone:footer */
   ...
   ```
3. **只写装饰性 CSS**（颜色/字体/间距/边框/阴影/圆角/hover 效果）
4. **不要写结构 CSS**（Grid/position/display/z-index 等——伯喈已在 preview-base 中搭好）
5. 完成后标注 `zone=design · 完成`，等待伯喈注入 preview-base 供主公审核。

### 设计迭代

主公审核 preview-base 后：
- 通过 → 进入 Step 7（部署）
- 不通过 → 主公描述问题 → 文姬修改 CSS → 重新提交 zone=design

## 伯喈（知识总管）操作指南

### Step 1：生成 preview-base

执行 `npx quartz build` → 复制 `public/index.html` → 注入 `<style id="design-css">` → 放入 `construction-site/`。

### Step 2：通知文姬启动

在 `oqc-通信文件.md` 写入 zone=layout 信息，通知文姬读取操作指南。

### Step 3：等待文姬风格询问

不干预文姬的 style-inquiry 流程。

### Step 4：注入文姬 CSS 到 preview-base

从通信文件读取 zone=design 的 CSS → 写入 `<style id="design-css">` 标签内 → 通知主公审核。

### Step 5：转译为 Quartz 格式

将 CSS 按 @zone 拆解，用 diff 格式写入 `custom.scss`。

### Step 6：构建部署

`npx quartz build` → 逐条检查 deployment-checklist → `git push`。
