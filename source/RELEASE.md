# OQC v1.2.0 Core release notes

This isolated core adds profile-selected presentation, centered article images, the `--site` alias, and an optional profile-driven 16:9 HomeHero.

It publishes the smallest complete chain: Profile → presentation → content mirror → Quartz build → Git commit and non-force push. The previous certification, reconciliation, approval, incident, and evidence layers are not included.

Both `standard-design` and `aisz-console` completed visual review. The AISZ path also completed a real GitHub Pages publication.
